## 1. Resumen ejecutivo

El proyecto funciona de punta a punta en local (con JDK 17, Postgres en Docker y la URL de la API redirigida), pero no está listo para que otra persona o un agente lo levante: el build falla con JDK 21, el front local habla con producción, el lint falla, no hay CI y hay un secreto JWT publicado. Base de tests: 16 unitarios de servicios + 1 `contextLoads`, 52 % líneas / 9 % ramas en el back y 0 % en el front.
